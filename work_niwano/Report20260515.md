## 2. Claude Code — AI 活用

### 3-1. ファイルアクセス制御
- `.claude\settings.json` でファイルアクセスを制御
- `*.env` に対する読み取り・書き込みを拒否

### 3-2. agent の作成

| agent | 使い方 | 成果物 |
|----------|--------|--------|
| コードレビュアー | `code-reviewer エージェントでレビューして` | `code-review_yyyymmdd.md` |
| マーケットリサーチャー | `market-researcher エージェントで調査して` | `market-research_yyyymmdd.md` |
| QA 管理者 | `qa-agent を使って全テストを実行してエラーを報告して` | `test-results.md` |

QA 管理者 agent の主な機能：
- テスト全体の実行・レポート
- テストコードの自動生成
- テストケースの出力
- カバレッジ計測と改善提案
- リグレッションチェック

### 3-3. Skill の作成
- プロジェクトフォルダの `.claude\skills\` に配置
- 制限：VSCode の拡張サイドバーチャットは非対応
  - ターミナルから `claude --add-dir .` で有効化
- 作成した skill：
  - `brainstorm`（設計・アーキテクチャの壁打ち相手）— 実行ログは `brainstorm.md` に保存

### 3-4. Agent 機能の Skill への分割
- 以前に作成した Agent の機能を Skill に分割
- `code-reviewer` から Skill `code-review` を分割
- `market-researcher` から Skill `market-research` を分割
- `qa-agent` から Skill `qa-guidelines` を分割

## 3. テスト整備

### 4-1. Vitest / Playwright テストの作成・実行
- QA 管理者 agent を使ってテストを自動生成・実行
- テストケースは `test-cases_yyyymmdd.xlsx` に出力
- レポートは `test-results.md` に出力

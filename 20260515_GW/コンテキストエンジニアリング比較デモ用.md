# コンテキストエンジニアリング比較デモ用

# ◎×ゲーム作成
会社のグループワーク発表で使用する
「コンテキストエンジニアリング」の比較デモ用として、
◎×ゲームを作成してください。

---

# 背景

このデモでは、

「AIに雑に依頼した場合」

と

「コンテキストエンジニアリングを行った場合」

の差を比較します。

そのため、
単に動くコードではなく、

- 保守性
- 可読性
- 拡張性
- 設計の綺麗さ

が分かる構成にしてください。

---

# 使用技術

- HTML
- CSS
- Vanilla JavaScript
- 外部ライブラリ禁止

---

# 必須機能

- 3×3の◎×ゲーム
- プレイヤー交互入力
- 勝敗判定
- 引き分け判定
- 現在ターン表示
- リセット機能

---

# 設計要件

以下を特に重視してください。

## 1. 責務分離

- UI描画
- ゲームロジック
- 状態管理

を分離してください。

---

## 2. 可読性

- 初心者でも理解できる命名
- 適切なコメント
- 関数を小さく分割

を意識してください。

---

## 3. 拡張性

後から以下機能を追加しやすい構造にしてください。

- CPU対戦
- スコア機能
- 難易度設定
- アニメーション

---

## 4. 保守性

- マジックナンバー禁止
- 定数化
- 重複コード削減
- シンプルな状態管理

を行ってください。

---

# UI要件

- シンプル
- 見やすい
- 発表向け
- レスポンシブ対応
- ミニマルデザイン

---

# ファイル構成

以下3ファイルに分割してください。

- index.html
- style.css
- script.js

---

# 特に重要

このコードは、

「新人がAIに雑に依頼して作ったコード」

との比較で使用します。

そのため、

- AI任せのコードとの差
- 設計品質の差
- 可読性の差
- 拡張性の差

が分かりやすい実装にしてください。

---

# 出力形式

各ファイルごとに、
ファイル名を明記して出力してください。

例：

```txt
# index.html
(code)

# style.css
(code)

# script.js
(code)
```

---

# 最重要ポイント

「ただ動くコード」

ではなく、

「長期運用できるコード」

を意識して実装してください。

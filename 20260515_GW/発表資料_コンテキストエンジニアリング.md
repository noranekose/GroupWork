# AIを使いこなす技術

# 〜コンテキストエンジニアリングとは？〜

---

# 1. コンテキストエンジニアリングとは

コンテキストエンジニアリングとは、

AIに渡す「情報・状況・履歴・ルール」などの
文脈（Context）を設計し、
AIの理解力と出力品質を高める技術。

---

## 簡単に言うと

AIに

* 何を見せるか
* どんな状況を共有するか
* どんな前提を与えるか

を設計すること。

---

# 2. なぜ重要なのか

AIは、
「知識」だけで動いているわけではない。

AIは、
入力された文脈（コンテキスト）から
次に最も自然な出力を予測している。

つまり、

---

## 文脈が悪いと、

## AIの理解も悪くなる

---

## 例

### 悪い例

```txt
◎×ゲーム作って
```

AIは、

* どんなデザイン？
* どの言語？
* どのレベル？
* 何が必要？

を推測するしかない。

---

### 良い例

```txt
HTML/CSS/JavaScriptで、
初心者向けの◎×ゲームを作成してください。

3×3の盤面、
勝敗判定、
引き分け判定、
リセット機能を実装してください。

発表デモ用なので、
シンプルで読みやすいコードにしてください。
```

AIが状況を理解しやすくなる。

---

# 3. プロンプトエンジニアリングとの違い

---

## プロンプトエンジニアリング

AIへの「指示文」を工夫する技術。

### 例

* 箇条書きで出力
* 丁寧に説明
* ステップごとに考える

---

## コンテキストエンジニアリング

AIに渡す「情報全体」を設計する技術。

### 例

* コード全体を共有する
* 仕様書を読ませる
* 過去履歴を渡す
* 制約条件を共有する

---

# 4. 違いまとめ

| 項目 | プロンプトエンジニアリング | コンテキストエンジニアリング |
| ---- | -------------------------- | ---------------------------- |
| 対象 | 指示文                     | 情報全体                     |
| 目的 | 出力を調整                 | AIの理解を改善             |
| 主役 | 命令                       | 文脈                         |
| 例   | 「箇条書きで答えて」       | 「仕様書を読ませる」         |

---

# 5. なぜ今、

# コンテキストエンジニアリングが重要なのか

最近のAIは、
単純な指示だけではなく、

「大量の情報を理解する能力」

が大幅に向上している。

---

## 特に重要なのは

* ソフトウェア開発
* Cursor
* ChatGPT
* Copilot
* AIエージェント

など。

---

## つまり

これからは、

「どう命令するか」

だけではなく、

---

# 「AIに何を見せるか」

---

が重要になる。

---

# 6. Cursorと

# コンテキストエンジニアリング

Cursorは、
コンテキストエンジニアリングと非常に相性が良い。

---

## なぜか？

Cursorは、

* コード全体を見る
* 複数ファイルを読む
* 過去コードを理解する
* プロジェクト構造を把握する

ことができるから。

---

# 7. 実践編

# AIに◎×ゲームを作らせる

---

# 実演①

# 文脈が少ないパターン

```txt
HTMLで◎×ゲーム作って
```

---

## 起こりやすい問題

* AI任せになる
* デザインが不安定
* コード構造がバラバラ
* 余計な機能追加
* 修正しづらい

---

# 実演②

# コンテキストを与えたパターン

```txt
HTML/CSS/JavaScriptで、
シンプルな◎×ゲームを作成してください。

# 背景
会社の発表デモ用アプリです。

# 目的
コンテキストエンジニアリングの重要性を説明したいです。

# 要件
- 3×3の盤面
- プレイヤーは交互に入力
- 勝敗判定
- 引き分け判定
- 現在の手番表示
- リセットボタン

# 制約
- index.html 1ファイルのみ
- 初心者でも読めるコード
- コメント付き
- シンプルなUI
- 余計な機能を追加しない

# 出力形式
完成コードのみ出力してください。

# ブラウザで context-engineering-demo/index.html を開くと動作します。
```

---

# 8. 比較

| 文脈が少ない   | コンテキストを与えた |
| -------------- | -------------------- |
| AIが推測する   | AIが理解しやすい     |
| 出力が不安定   | 出力が安定           |
| 修正しづらい   | 修正しやすい         |
| AI任せ         | AIを誘導できる       |

---

# 9. 重要な考え方

AI時代に重要なのは、

---

# 「AIに何を命令するか」

ではなく、

# 「AIにどんな文脈を渡すか」

---

である。

---

# 10. まとめ

コンテキストエンジニアリングとは、

AIに渡す情報や状況を設計し、
AIの理解を助ける技術。

---

## 重要なのは

* 背景
* 目的
* 要件
* 制約
* 過去情報
* プロジェクト全体

を整理してAIに渡すこと。
